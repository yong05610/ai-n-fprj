# 변경관리내역서 검토 — 학습경로 설정 (No.1~8)

작성: PM, 2026-11-09. 대상: 사용자가 작성한 `변경관리내역서.pdf`(2026-11-09 14:04 판, 학습경로 설정 No.1~8). **번호는 내역서의 No 를 그대로 쓴다.** 각 항목을 현재 코드와 대조했다(`frontend/components/LearningPathWizard.tsx`, `frontend/lib/planText.ts`, `backend/schemas.py`, `backend/prompts.py`, `backend/main.py` 대시보드 요약). 이전 판(번호가 내역서와 달랐던 것)은 이 문서로 대체한다.

**분류 기준(제안)**
- 유형: 개선(있는 기능을 낫게) / 신규(없는 기능) / 연구(방향 결정 필요)
- 대책유형: 즉시(S 묶음으로 바로) / CR(별도 변경으로 테스트 후) / 운영(코드 변경 없음) / 연구(결정 후 CR)
- 규모: S = 문구·배치·간단한 계산(반나절), M = AI 프롬프트·응답 항목 변경(1~2일, 실제 AI 확인 비용), L = 새 흐름·새 API(3일 이상)

## 2. 공통 선행 조건
- **목업 먼저:** 학습 경로 설정 화면을 바꾸는 항목(No.1①, 2, 3 화면, 4 1단계, 5)은 PM 이 `mockup/index.html` 의 `page-path` 를 먼저 고치고, 개발 지시서에 목업과 나란히 비교한 표를 요구한다(5C 교훈).
- **테스트 기간 중 배포:** 테스터 화면이 바뀐다. 즉시 묶음은 혼란을 줄이는 변경이라 반영하되, 반영 날짜를 기록해 설문 응답과 구분한다.
