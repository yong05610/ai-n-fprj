# 변경관리내역서 검토 — 학습경로 설정 (PM)

작성: PM, 2026-11-09. 대상: 사용자가 작성한 `변경관리내역서.pdf`(인수 테스트 보완 사항, 학습경로 설정 부분). 각 항목을 현재 코드(`frontend/components/LearningPathWizard.tsx` 등)와 대조했다. **아직 CR 번호를 주지 않았다.** 사용자가 항목별로 진행 여부를 정하면 그때 CR 로 등록한다.

규모: S = 문구·스타일(반나절 이내), M = 화면 구조 또는 AI 프롬프트 변경(1~2일), L = 새 흐름·새 API(3일 이상).

## 내역서 양식에 대해
- **표지:** "태광엠앤에스 ERP 시스템 구축사업"과 다른 회사 로고가 그대로 있다. PaceMate 로 바꿔야 한다. 이 상태로는 저장소에 올리지 않는다(지금도 커밋하지 않음).
- `유형`·`대책유형` 칸이 비어 있다. 제안: 유형 = 오류 / 개선 / 신규, 대책유형 = 즉시 수정 / CR 등록 / 연구 / 보류.
- 3번의 "학습과제 결정" 행에 "예를 들어", "시" 처럼 글이 나뉜 곳이 있다(표 줄바꿈으로 보임).
