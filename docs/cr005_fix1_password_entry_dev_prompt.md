## 배경 (사용자 배포 환경 확인, 2026-10-30)
- 배포 환경에서 다른 브라우저로 암호 로그인 → **같은 학습 기록으로 들어가는 것 확인(성공)**.
- 문제: 첫 화면(동의 안내 모달)의 입구 `이미 암호를 등록했어요(사용자 인증)` 가 **동의 버튼 아래에 10px 글자 링크**(`.link-btn`)로만 있다. 사용자가 이를 못 보고 **"동의하고 시작하기"를 먼저 누르기 쉽다.** 그러면 새 익명 사용자가 하나 더 생기고, 학습자는 "내 기록이 사라졌다"고 느낀다.

## 바꿀 것 (`frontend/components/ConsentModal.tsx`, 필요하면 `app/globals.css`)
1. **위치:** 입구를 모달 **위쪽**으로 옮긴다. 안내 문장 `서비스를 시작하기 전, 아래 내용을 확인해 주세요.` 바로 아래, `수집하는 정보` 제목보다 위.
   - 이유: 학습자는 위에서 아래로 읽고 맨 아래에서 동의한다. 동의 버튼에 닿기 전에 "나는 이미 등록한 사람"인지 먼저 고를 수 있어야 한다.
2. **모양:** 테두리가 있는 작은 안내 상자 1개.
   - 첫 줄(굵게): `다른 기기에서 암호를 등록했나요?`
   - 둘째 줄(보통 글자): `등록한 암호로 로그인하면 같은 학습 기록으로 들어가요.`
   - **버튼:** `암호로 로그인` — 기존 버튼 스타일 `btn secondary`(모달 아래 "동의하지 않음"과 같은 크기·글자). 링크 모양(`.link-btn`)은 쓰지 않는다.
   - 상자 색은 기존 CSS 변수만 사용(새 색 하드코딩 금지). 강조는 하되 동의 버튼(`btn`, 파란 채움)보다 눈에 띄지 않게 한다.
3. **기존 아래쪽 링크는 없앤다**(입구는 한 곳만). 버튼의 `id="password-login-link"` 는 새 버튼에 유지한다.
4. 그대로 유지할 것: 기능이 꺼져 있으면(`onPasswordLogin` 없음) 상자 전체가 보이지 않음, `busy` 일 때 버튼 비활성, 버튼을 누르면 지금의 암호 입력 화면(`passwordMode`)으로 바뀜, 암호 입력 화면의 문구와 동작.
5. 화면 폭 360px(휴대폰)에서 가로 스크롤이 생기지 않고 버튼 글자가 줄바꿈으로 깨지지 않을 것.
