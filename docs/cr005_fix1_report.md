- 실제 휴대폰과 배포(Vercel) 화면은 미확인. 배포 반영은 push 후 사용자 확인이 필요하다.
- 확인용으로 `frontend` 에서 `npm run build` 를 실행했다. 이미 떠 있던 포트 3000 개발 서버(PID 42064, 내가 띄운 것이 아님)는 건드리지 않았지만 `.next` 폴더를 공유하므로, 그 화면이 이상하면 개발 서버를 다시 시작하면 된다.
