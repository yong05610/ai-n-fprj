## 발견 사항
1. **가끔 분량이 너무 얇다(수정 요청 없음, 관찰).** 위 실제 호출에서 가톨릭 1,060분(성경 전체를 약 18시간), Python 395분(과제당 약 28분)이 나왔다. 원인 확인을 위해 같은 조건으로 4번 더 돌리니 가톨릭 2,920~3,540분, Python 1,860~2,160분으로 정상 범위였다(우연한 편차). "과제 시간은 의견의 시간을 따르고 현실적 총량" 규칙을 2단계에 더한 안도 시험했으나 개선이 뚜렷하지 않고 1번 실패해 **채택하지 않았다.** 화면의 가용 시간 막대가 적게 쓴 계획을 보여 주므로 사용자 테스트에서 관찰한다.
2. 시간: 18~37초(개발팀 37초 포함). 지시서의 25~30초보다 길 수 있다. 화면에서 기다림이 길게 느껴지는지는 배포 후 확인하고, 필요하면 대기 안내 문구를 추가한다.
