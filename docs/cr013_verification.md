## 수정 요청 (CR-013 수정 1, 작음)
**삭제 응답을 못 받고 다시 시도하면 "실패"로 보인다.** 서버는 이미 지운 학습을 다시 지우려 하면 404 를 준다(`_get_owned`). 화면은 모든 오류를 실패로 다뤄, 첫 요청이 서버에서 성공했는데 응답만 끊긴 경우(느린 망, Render 재시작 중) `다시 시도` → 404 → "삭제하지 못했어요"가 뜨고 목록도 다시 불러오지 않는다. 학습은 실제로 지워졌는데 화면에는 남아 있다(다른 화면으로 가면 사라짐).
- 고칠 것: `DELETE /api/goals/{id}` 가 **404 면 이미 지워진 것으로 보고 성공과 같이 처리**(창 닫고 다시 불러오기). 403 등 다른 오류는 지금처럼 실패.
- 시험 1건(404 → 성공 처리와 다시 불러오기).
- 검증 체크리스트의 "응답을 못 받은 재시도" 유형이다.
