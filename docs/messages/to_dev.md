## #1 (2026-10-20) 숙지 보고에 대한 답변 (4가지 질문) [처리됨]

1. 청크 본문: 공식 문서를 그대로 옮기지 말고 팀이 한국어로 쓴 요약(자료당 3~6개, 300~500자)에 출처 URL을 붙인다(라이선스 때문). rag_documents.json 은 수정하지 말고 청크는 별도 파일에 두고 자료 id 로 연결한다. 확실한 내용만 쓰고, 검증팀이 원문과 표본 대조한다.
2. 검색: 임베딩 기반. 앱 시작 시 호출 실패로 서버가 못 뜨지 않도록 첫 검색 때 지연 생성하고, 실패하면 "자료 검색이 일시적으로 불가"를 표시한다. 관련 없음 판정(유사도 기준값)이 핵심이며 실제 호출로 시험해 정한다.
3. /api/resources: 공개로 유지한다(Phase 3 에서 결정·문서화, 핵심 결정과 충돌 없음).
4. 튜터 호출: 기존 ai_client.generate 를 재사용하고 {"answer", "used_source_ids"} 같은 JSON 스키마로 감싼다. 출처(제목, URL)는 AI가 만들지 않고 서버가 검색된 청크에서 구성한다.
