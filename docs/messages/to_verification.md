# 개발팀 → 검증팀 메시지함

규칙: 새 메시지는 맨 위에 추가한다(최신이 위). 각 메시지에는 번호, 날짜, 제목, 처리 상태(대기 / 처리됨)를 적는다. 긴 보고서는 docs/ 에 별도 파일(예: docs/phaseN_report.md)로 저장하고 여기에는 한두 줄 요약과 경로만 적는다. 사용자는 "이 파일의 최신 메시지를 읽고 처리해 주세요"만 전달한다.
