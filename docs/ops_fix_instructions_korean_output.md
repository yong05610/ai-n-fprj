# 수정 지시 — 영어로 입력하면 AI 추천이 영어로 나오는 문제 (PM, 2026-10-25)

대상: 현재 main. 끝나면 docs/ops_fix_report_korean_output.md 로 보고하고 멈춘다. Phase 7 은 시작하지 않는다. 작은 수정이다.

## 1. 문제 (사용자 화면 캡처와 코드로 확인)
학습 분야를 영어로 입력("vibe coding")하자 직무 예시와 세부 과정 이름이 **영어**로 나왔다("Vibe Code Developer", "Creative Coding Specialist", "Vibe Coding Fundamentals"). 한국어 서비스인데 입력 언어를 따라 AI 가 영어로 답한다. 원인: `backend/prompts.py` 의 프롬프트 중 한국어 출력 지시가 있는 것은 튜터(`TUTOR_SYSTEM_PROMPT`)와 인사이트뿐이고, **`ROLE_IDEAS_SYSTEM_PROMPT`(직무 예시), `PATH_RECOMMEND_SYSTEM_PROMPT`(과정·수준 추천), `PLAN_GENERATE_SYSTEM_PROMPT`(계획 생성)에는 언어 지시가 없다.** 지금까지 한국어 입력으로만 시험해서 드러나지 않았다.

**PM 재현 실험(실제 OpenAI, 직무 예시 호출, 한글 글자 비율):** 입력 `vibe coding` 4회 → 한국어 75%, **영어 0%**, 한국어 100%, **영어 0%**(같은 입력인데 절반이 영어). 입력 `VIBE CODING` 2회 → 영어 0%, 영어 48%(혼합). 즉 이 결함은 항상이 아니라 **호출마다 랜덤**으로 나오며(사용자도 수정 없이 한국어로 돌아온 것을 확인), 사용자 테스트에서 일부 테스터가 영어 결과를 볼 수 있다. 수정 후 PM 이 같은 입력으로 6회 이상 재호출해 모두 한국어인지 확인한다(통과 기준: 직무 예시와 과정 이름이 모두 한국어, 입력한 분야 이름만 원어).
## 2. 수정 (필수)
1. 위 세 프롬프트에 규칙을 추가한다: "사용자 입력이 영어나 다른 언어여도 **모든 출력 텍스트(직무·목표 예시, 과정 이름과 설명, 수준 이름과 설명, 과제 제목과 설명, 조언)는 한국어로 쓴다.** 기술 용어와 고유명사(React, SQL, Python 등)는 원어 표기를 그대로 써도 된다. 사용자가 입력한 분야 이름은 바꾸지 않고 그대로 인용한다(예: 'vibe coding'은 'vibe coding'으로 두되 설명은 한국어)."
2. 한국어 지시가 이미 있는 튜터와 인사이트 프롬프트는 변경하지 않는다(확인만).
3. 서버 검증은 추가하지 않는다(기술 용어 때문에 한글 비율 검사가 오거부를 낼 수 있음). 대신 아래 실제 호출로 확인한다.

## 3. 하지 않는 것
다국어 지원 기능, 입력 언어 감지, 화면 문구 변경, 스키마·API 변경.

## 4. 테스트와 검증 기준
- backend: 세 프롬프트에 한국어 출력 지시 문구가 포함되는지 확인하는 테스트(문자열 포함 검사), 기존 772건 통과.
- **실제 OpenAI 호출(필요한 만큼, 최대 4회):** 분야 입력을 영어("vibe coding", "data analysis", "web development")로 직무 예시와 과정 추천을 각각 호출하여, 응답의 직무 예시와 과정·수준 이름과 설명이 **한국어인지**를 한글 글자 비율(숫자로만 보고, 원문 없이)로 보고한다. 한국어 입력 1회도 함께 돌려 이전과 다르지 않은지 확인한다. 계획 생성은 영어 분야로 1회 호출해 과제 제목·설명이 한국어인지 확인한다.
- PM 재검증: 같은 영어 입력으로 실제 호출 3회를 직접 확인한다.
