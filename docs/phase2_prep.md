## Task 2.1 — 동의 및 개인정보 안내 문구

### 온보딩 모달 동의 문구 (확정안)

> **PaceMate 학습 서비스 이용 안내**
>
> 서비스를 시작하기 전, 아래 내용을 확인해 주세요.
>
> **수집하는 정보**
> - 이름·이메일 등 개인 식별 정보는 수집하지 않습니다.
> - 학습 목표, 학습 기록, 회고, AI 튜터 대화 이력이 저장됩니다.
> - 모든 데이터는 **익명 UID**와 연결되며, 본인 외에 열람할 수 없습니다.
>
> **AI 활용**
> - AI가 학습 계획, 수준 제안, 튜터 답변을 생성합니다.
> - AI 답변은 참고용이며 정확성을 직접 확인해 주세요.
> - 학습 기록과 회고가 AI 튜터의 개인화 답변에 활용됩니다.
>
> **데이터 삭제**
> - [내 정보·설정] 메뉴에서 언제든지 모든 학습 데이터 삭제를 요청할 수 있습니다.
> - 삭제 요청 시 학습 목표·기록·회고·대화 이력이 모두 삭제됩니다.
> - 이 서비스는 베타 테스트 중이며, 테스트 종료 후 데이터 삭제 절차를 안내드립니다.

**버튼 구성**
- `[동의하고 시작하기]` — 필수 동의 후 익명 UID 생성 및 서비스 진입
- `[동의하지 않음]` — 개인화 기능 진입 불가, 공개 안내 페이지만 표시

### 동의 버전
- 버전: `v1.0`
- 날짜: 2026-10-19

## Task 2.2 — 동의 전 데이터 저장 차단 흐름 확정

```
[첫 접속]
    │
    ▼
[온보딩 모달 표시]
    │
    ├─ [동의하지 않음] ──▶ 개인화 기능 진입 불가 (로컬 상태 유지, UID/DB 미생성)
    │
    └─ [동의하고 시작하기]
            │
            ▼
       [Firebase 익명 Auth signInAnonymously() 호출]
            │
            ▼
       [Firebase UID 발급 성공]
            │
            ▼
       [Firestore: consent_records 문서 생성]
       {user_id, terms_version: "v1.0", privacy_agreed: true,
        ai_use_agreed: true, consented_at: now()}
            │
            ▼
       [대시보드 진입 및 이후 학습 데이터 저장 허용]
```

**원칙:**
- `signInAnonymously()` 호출은 동의 버튼 클릭 이후에만 실행
- 동의 전에는 `localStorage`·`sessionStorage`·Firestore 어디에도 UID 또는 학습 데이터를 저장하지 않음
- 백엔드는 모든 보호된 API에서 Firebase ID Token을 검증하며, 토큰이 없으면 401 반환

## Task 2.7 — 연락처 분리 원칙

- **원칙:** 설문 응답과 연락처는 동일 폼에 수집하지 않습니다.
- **방법:**
  - 설문은 완전 익명으로 운영
  - 추가 인터뷰를 원하는 참여자의 연락처는 채팅(DM)/이메일 등 **개인 채널을 통해 별도로** 수집
  - 연락처와 설문 응답을 연결하지 않으며, 테스트 종료 후 연락처는 즉시 파기
