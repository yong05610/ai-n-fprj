## 미검증 (사용자가 브라우저에서 확인)
1. 마법사 새 흐름(분야 → 직무 예시 → 목표 → 세부 과정)과 직무 chip 을 누르면 목표칸에 채워지는지.
2. 시작일을 아무 날로 고르고, 겹침 오류가 날짜칸 아래에 뜨며 날짜를 바꾸면 지워지는지.
3. 타이머를 켠 채 새로고침(F5)하거나 학습을 전환했다 돌아와도 진행 중 과제가 선택되어 보이는지, "그 학습으로 돌아가기" 버튼.
4. "학습 목표" 입력칸에 브라우저 자동완성 말풍선이 더 이상 뜨지 않는지.
5. Firebase 모드(현재 .env)에서도 위가 같은지.
- Firebase 콘솔의 문서 생성은 사용자가 확인해야 한다.

## 열린 항목 (수정 지시 아님, 기록)
- `POST /api/goals`(직접 생성)는 여전히 시작일을 "이번 주 월요일"로 고정한다. 프론트가 쓰지 않는 경로라 영향은 없다. 쓰게 되기 전에 정리한다 → post_mvp_backlog.md 후보.
- `POST /api/path/recommend` 프롬프트가 직무를 계속 요청해 토큰을 조금 더 쓴다. 이번에는 프롬프트를 바꾸지 않기로 했다(개발팀 판단 동의). 실제 모델로 다시 확인할 때 같이 정리한다.
- 시작일이 주 중간이어도 첫 주 과제량은 전체 주당 시간으로 배정된다(지시서대로 범위 밖).
- docs/phase1_design.md 사용자 여정 문장은 PM 이 새 흐름에 맞게 고쳤다.
