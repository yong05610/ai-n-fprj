## 5. 사용자가 직접 눌러 볼 항목 (조각이 verified: true 로 바뀐 뒤)
1. 학습을 만든 뒤 AI 튜터를 열어 "파이썬 리스트에 값 추가하는 법" 질문 → 답변과 출처(Python 자료구조 공식 가이드)가 말풍선과 우측 패널에 보이는가.
2. "학습 의욕이 안 생길 때 어떻게 하죠?" → "참고한 등록 자료가 없어요" 안내가 붙는가.
3. "김치찌개 레시피" → 학습 관련 질문에만 답할 수 있다는 거절 문구가 나오는가.
4. 새로고침(F5) → 같은 대화와 목록이 그대로 복원되는가. 주소창의 #tutor/… 해시를 지우면 새 대화 화면이 되는가.
5. 목록에서 이전 대화를 눌러 이어서 질문, "＋ 새 대화"가 빈 화면을 여는가.
6. 회고를 남긴 뒤 관련 질문 → 우측 "최근 회고"에 보이고 답변이 내 상황을 반영하는가. 회고를 삭제하면 사라지는가.
