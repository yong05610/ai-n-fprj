- wikidocs(점프 투 파이썬): 봇 요청에 403, 내용 확인 불가. British Council LearnEnglish: 연결 실패. Kaggle Learn, Khan Academy, freeCodeCamp: 자동 요청으로 제목을 읽지 못함(브라우저에서는 열릴 수 있으나 이번 확인 기준을 못 채움). Linux Journey: 주소가 다른 사이트(labex.io)로 이동해 제외.
