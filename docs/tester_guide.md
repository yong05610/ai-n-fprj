- **문의:** [ 연락처 ]

## 1. 시작하기 전에
1. **본인이 평소 쓰는 PC나 휴대폰 브라우저**로 열어 주세요. 로그인 정보가 그 브라우저에 저장되어, 다음에 열면 이어서 쓸 수 있습니다.
2. **여러 사람이 쓰는 PC(학교, PC방)** 라면 시크릿 창(Chrome `Ctrl+Shift+N`, Edge InPrivate)을 쓰세요. 창을 닫으면 기록에 다시 들어갈 수 없으니, 계속 쓰려면 아래 3번의 암호를 먼저 등록하세요.
3. 처음 열 때 **"서버를 준비하고 있습니다. 잠시만 기다려 주세요."** 가 1분 가까이 보일 수 있습니다. 무료 서버가 쉬고 있다가 깨어나는 시간이니 기다려 주세요. 90초가 지나면 **다시 시도** 버튼이 나옵니다.
4. 첫 화면에서 안내를 읽고 동의하면 시작됩니다. **이름, 이메일 같은 개인 정보는 받지 않습니다.**
5. 학습 목표나 회고에 **본인 이름, 연락처 같은 개인 정보는 쓰지 마세요.**

## 2. 이렇게 써 보세요 (순서대로)
| 순서 | 메뉴 | 해 볼 것 |
|---|---|---|
| 1 | 학습 경로 설정 | 공부하려는 분야와 지금 수준, 목표, 기간을 고르고 AI 추천으로 학습 경로 만들기 |
| 2 | 학습 과제 계획 | AI 가 제안한 과제를 보고 고치거나 그대로 **계획 확정** |
| 3 | 학습 실행 기록 | 타이머로 공부 시간을 재거나 직접 입력해 기록 1건 이상, **한 줄 회고** 쓰기 |
| 4 | AI 튜터 | 공부하다 막힌 것을 질문하기 |
| 5 | 종합 학습 분석 | AI 인사이트(학습 패턴 분석) 받아 보기 |
| 6 | 대시보드 | 오늘 할 과제와 진행률 확인 |

- AI 의 답은 참고용입니다. 틀린 내용이 있으면 아래 5번 피드백으로 알려 주세요.
- 과제의 추천 요일은 마감일이 아닙니다. 놓쳐도 괜찮습니다.

## 3. 다른 기기에서 이어 쓰기 (암호)
PC 에서 쓰던 기록을 휴대폰이나 다른 PC 에서도 보고 싶을 때 씁니다.

1. **등록:** 쓰던 기기에서 **내 정보·설정 → 다른 기기에서 이어 쓰기** 카드에 암호와 암호 확인을 입력합니다.
   - 8자 이상, 영문·숫자·특수문자를 모두 포함, 공백 없음
   - 다른 사이트에서 쓰는 암호는 쓰지 마세요.
2. **다른 기기에서:** 첫 화면 위쪽의 **`암호로 로그인`** 을 누르고 암호만 입력합니다. **이때 "동의하고 시작하기"를 먼저 누르지 마세요.** 누르면 빈 기록이 새로 생깁니다.
   - 이미 다른 기록으로 들어가 있는 기기라면: 내 정보·설정 → 다른 기기에서 이어 쓰기 → **다른 기기에서 등록한 암호로 로그인**
3. **암호는 꼭 메모하거나 브라우저·비밀번호 관리 앱에 저장하세요.**
   - **"암호 찾기"는 없습니다.** 서버도 암호를 알 수 없게 저장하기 때문입니다.
   - 잊었다면: 아직 로그인되어 있는 기기에서 **내 정보·설정 → 다른 기기에서 이어 쓰기 → 암호 바꾸기** 로 새 암호를 정하면 됩니다(예전 암호를 묻지 않습니다).
   - **모든 기기에서 로그아웃된 상태로 암호를 잊으면 그 기록은 되찾을 수 없습니다.**
4. "이 암호는 쓸 수 없어요"가 나오면 너무 흔한 암호이거나 쓸 수 없는 암호입니다. 다른 암호를 정해 주세요.
5. 같은 곳에서 여러 번 틀리면 10분 정도 로그인이 막힙니다. 잠시 뒤 다시 해 주세요.

## 4. 내 데이터 지우기
- 언제든 **내 정보·설정 → 내 학습 데이터 삭제** 로 모든 학습 기록을 지울 수 있습니다(되돌릴 수 없음).
- 테스트가 끝나면 테스트 데이터 정리 일정을 따로 알려 드립니다.
