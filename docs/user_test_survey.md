# 사용자 테스트 설문 문항 (최종안)

작성: 검증/PM, 2026-10-27. 대상: TASK Phase 8 사용자 테스트(테스터 5명 이상). 이 문서의 문항으로 **사용자가 Google Forms(또는 Tally)에서 설문을 만든다.** 이전 구성안(`docs/phase2_prep.md` Task 2.6, 6문항)을 대체한다.

## 0. 만들 때 지킬 것
- **익명:** 이름, 이메일, 연락처, 학교·회사, PaceMate 계정 ID 를 묻지 않는다. Google Forms 설정에서 "이메일 주소 수집"을 **끈다**(로그인 요구도 끈다).
- 예상 소요 5~7분. 필수 문항은 ★ 표시만 필수로 둔다.
- 설문 링크는 만든 뒤 테스터 안내문에 넣는다(안내문은 따로 작성).
- 응답 결과는 Google Forms 의 요약(중앙값, 비율)과 주관식 원문으로 받아 PM 이 `docs/` 에 요약한다. 원문 전체를 저장소에 올리지 않는다.

## 3. 이전 구성안과 달라진 점
- 만족도를 "AI 계획", "AI 튜터", "참고자료", "인사이트"로 나눠 어느 AI 기능이 도움이 됐는지 구분한다(이전: AI 유용성 1문항).
- 진행 정도를 예/아니오 1문항에서 단계별 체크로 바꿔 어디서 멈추는지 보이게 했다.
- 후속 후보(타이머 일시정지, 계획 분량, 여러 기기 이어 쓰기)의 필요성을 확인하는 문항을 넣었다.
- 이전 메모의 "선호하는 로그인 방식" 문항은 뺐다. 방식은 사용자가 이미 정했다(CR-005: 사용자가 정한 암호, 2026-10-27).
